# وقتي — تطبيق تسجيل ساعات العمل وحساب تكلفة المشاريع

تطبيق ويب تقدّمي (PWA) شخصي، عربي بالكامل وبدعم RTL، لتسجيل الوقت الفعلي لكل مشروع وحساب تكلفته بالريال السعودي بدقة الثانية. يعمل على iPhone وAndroid دون نشره في المتاجر، ويعمل دون اتصال بعد أول تحميل، وتُحفظ جميع البيانات محليًا على الجهاز (IndexedDB).

> **مهم:** افتراضيًا البيانات محلية 100٪ على الجهاز الذي ثبّت عليه التطبيق، بلا حسابات ولا خوادم. يمكن تفعيل مزامنة اختيارية بين الأجهزة عبر Dexie Cloud (انظر قسم «المزامنة بين الأجهزة»). في الحالتين صدّر نسخة احتياطية بانتظام من الإعدادات.

## الميزات

- **لوحة تحكم:** عدد المشاريع، إجمالي الساعات، إجمالي القيمة بالريال، المشاريع قيد التنفيذ، ملخص اليوم/الأسبوع/الشهر، رسم آخر 7 أيام، آخر المشاريع، مؤقت سريع.
- **المشاريع:** اسم، عميل، وصف، تاريخ بدء، حالة (جديد / قيد التنفيذ / متوقف مؤقتًا / مكتمل)، سعر ساعة خاص (افتراضيًا 250 ر.س)، ملاحظات، أرشفة، حذف بتأكيد.
- **المؤقت:** بدء / إيقاف مؤقت / استئناف / إنهاء، عرض الوقت والقيمة مباشرة، ملاحظة ونوع مهمة لكل جلسة. يمكن تشغيل مؤقت لكل مشروع في الوقت نفسه (افتراضيًا)، مع قائمة بالمؤقتات المفتوحة في الرئيسية وتنبيه بأن الساعات المحتسبة قد تتجاوز الوقت الفعلي، وزر «إنهاء جميع المؤقتات». يمكن تعطيل التزامن من الإعدادات فيعود شرط «مؤقت واحد فقط» مع طلب تأكيد عند التعارض. وقت التوقف المؤقت لا يُحتسب. تُحفظ توقيتات البداية والنهاية الفعلية في قاعدة البيانات، فلا يُفقد الوقت عند إغلاق التطبيق أو الانتقال للخلفية أو إعادة تشغيل الجوال، ويُنبّهك التطبيق عند فتحه إلى وجود جلسة مفتوحة.
- **الجلسات:** تعديل جلسة سابقة (تُوسم «معدّلة يدويًا» ويُعاد حساب تكلفتها)، تسجيل جلسة يدويًا (بداية/نهاية أو بداية/مدة)، منع المدد السالبة والمستقبلية، بحث وتصفية حسب المشروع والتاريخ، حذف بتأكيد.
- **الحساب:** `التكلفة = الثواني المحتسبة ÷ 3600 × سعر الساعة` دون أي تقريب للساعة الكاملة. سعر الساعة يُثبَّت لكل جلسة وقت تسجيلها؛ تغيير السعر الافتراضي أو سعر المشروع لا يمس الجلسات القديمة إلا إذا اخترت «إعادة احتساب» صراحة.
- **التقارير والتسعير:** إجمالي الساعات والتكلفة، توزيع الوقت حسب اليوم ونوع المهمة، جدول الجلسات، أداة تسعير (هامش٪ + مصاريف − خصم) مع عرض المعادلة، سعر نهائي للعميل مستقل عن تكلفة الوقت، طباعة/حفظ PDF.
- **النسخ الاحتياطي:** تصدير/استيراد JSON مع التحقق من صحة الملف وتحذير قبل الاستبدال (وضعا «دمج» و«استبدال»)، تصدير CSV متوافق مع Excel (UTF-8 BOM)، حذف جميع البيانات بتأكيد مزدوج، طلب التخزين الدائم من المتصفح.
- **التصميم:** Mobile-first، وضع فاتح وداكن، أزرار كبيرة للمس، حالات فارغة، إشعارات عربية، RTL كامل.

## الهوية البصرية

التطبيق يتبع هوية **Nav Builds** (navbuilds.net): ورق فاتح `#F2F3F1`، حبر `#111214`، لون إشارة برتقالي `#FF4A1C` يُستخدم بشُح، خطوط Alexandria للعناوين وIBM Plex Sans Arabic للنص وGeist Mono للأرقام (مستضافة ذاتيًا وتعمل دون اتصال). النظام موثّق ومقفل في `design.md`؛ أي تعديل بصري يبدأ من هذا الملف.

## التقنيات

| الطبقة | الاختيار | السبب |
| --- | --- | --- |
| الواجهة | React 18 + TypeScript + Vite 5 | خفيفة ومستقرة وسريعة البناء |
| التخزين | Dexie.js 4 (IndexedDB) + `dexie-react-hooks` | استعلامات حيّة، ترحيلات مخطط آمنة |
| المزامنة (اختيارية) | `dexie-cloud-addon` | مزامنة دون اتصال مع حل تعارضات، تُفعَّل بمتغير بيئة فقط |
| PWA | `vite-plugin-pwa` (Workbox) | manifest + service worker + تخزين مؤقت للعمل دون اتصال |
| التنسيق | CSS مخصص بمتغيرات | بلا اعتماديات إضافية، تحكم كامل بالـ RTL والثيم |
| الاختبار | Vitest + `fake-indexeddb` | اختبار منطق الحساب والمؤقت وقاعدة البيانات |

لا توجد أي خدمات خارجية أو مدفوعة.

## بنية المشروع

```
src/
  types.ts              نموذج البيانات (Project, WorkSession, ActiveTimer, Settings, BackupFile)
  db/db.ts              قاعدة بيانات Dexie + الإعدادات الافتراضية + مكان الترحيلات المستقبلية
  lib/calc.ts           منطق الحساب الخالص (تكلفة، ثوانٍ محتسبة، مؤقت، تحقق، تسعير) — قابل للاختبار
  lib/format.ts         تنسيق الأرقام والمدد والتواريخ والعملة
  services/timer.ts     بدء/إيقاف/استئناف/إنهاء المؤقت (مؤقت واحد فقط)
  services/sessions.ts  جلسات يدوية وتعديل وحذف
  services/projects.ts  إدارة المشاريع وتغيير السعر (مع/بدون إعادة احتساب)
  services/backup.ts    تصدير/استيراد/تحقق JSON، تصدير CSV، حذف الكل
  services/stats.ts     إحصائيات اللوحة والتقارير
  components/           مكوّنات الواجهة (المؤقت، النماذج، الشريط السفلي، الحوارات، الإشعارات)
  pages/                الصفحات: الرئيسية، المشاريع، تفاصيل المشروع، السجل، التقارير، الإعدادات
  i18n/                 النصوص (عربي افتراضيًا، بنية جاهزة لإضافة الإنجليزية)
public/icons/           أيقونات PWA (SVG + PNG 192/512)
scripts/gen-icons.mjs   توليد PNG من SVG
```

## التشغيل محليًا

المتطلبات: Node.js 18 أو أحدث.

```bash
npm install          # تثبيت الاعتماديات
npm run dev          # تشغيل بيئة التطوير على http://localhost:5173 (مع --host للوصول من الجوال)
npm test             # تشغيل الاختبارات (Vitest)
npm run build        # فحص الأنواع + بناء الإنتاج في مجلد dist/
npm run preview      # معاينة نسخة الإنتاج على http://localhost:4173
```

> ميزات PWA (التثبيت والعمل دون اتصال) تعمل في نسخة الإنتاج (`build` ثم `preview` أو الاستضافة)، وليس في `dev`.

## فتح التطبيق على الجوال وتثبيته (دون المتاجر)

### الخيار 1: على الشبكة المحلية (للتجربة)

1. شغّل `npm run build` ثم `npm run preview`.
2. اعرف عنوان IP لجهازك على الشبكة (مثل `192.168.1.10`).
3. افتح على الجوال: `http://192.168.1.10:4173`.
4. ملاحظة: على `http` (غير `localhost`) لن يعمل service worker ولن يظهر خيار التثبيت الكامل على iPhone. للتثبيت الحقيقي استخدم الخيار 2.

### الخيار 2: استضافة مجانية على HTTPS (موصى به)

التثبيت كتطبيق مستقل والعمل دون اتصال يتطلبان **HTTPS**. أي استضافة ثابتة مجانية تكفي، مثلًا:

- **GitHub Pages / Netlify / Cloudflare Pages / Vercel:** ارفع مجلد `dist/` (أو اربط المستودع واضبط أمر البناء `npm run build` ومجلد النشر `dist`).
- المشروع مبني بـ `base: './'` فيعمل من أي مسار فرعي، والتنقل داخلي بـ `#` فلا يحتاج إعدادات إعادة توجيه.

ثم على الجوال:

**iPhone (Safari):**
1. افتح رابط التطبيق في **Safari** (وليس Chrome).
2. اضغط زر **المشاركة** (المربع مع السهم).
3. اختر **«إضافة إلى الشاشة الرئيسية»** ثم **إضافة**.
4. افتح التطبيق من الشاشة الرئيسية؛ سيعمل بواجهة كاملة دون شريط المتصفح.

**Android (Chrome):**
1. افتح رابط التطبيق في Chrome.
2. اضغط القائمة **⋮** ثم **«تثبيت التطبيق»** (أو «إضافة إلى الشاشة الرئيسية»).
3. أكّد التثبيت.

بعد أول فتح تُخزَّن ملفات التطبيق محليًا ويعمل دون اتصال. عند نشر إصدار جديد يظهر شريط «يتوفر تحديث» داخل التطبيق؛ التحديث لا يمس بياناتك.

## المزامنة بين الأجهزة (اختيارية)

افتراضيًا التطبيق محلي 100٪. لتفعيل المزامنة بين أجهزتك يستخدم التطبيق **Dexie Cloud** (خدمة مزامنة لقواعد Dexie، لها خطة مجانية للاستخدام الشخصي). التطبيق يبقى يعمل دون اتصال، وتُدمج التغييرات عند عودة الاتصال، ويُطبَّق شرط «مؤقت واحد فقط» عبر جميع الأجهزة.

**الإعداد مرة واحدة (من جهازك):**

```bash
npx dexie-cloud create          # يطلب بريدك ويرسل رمزًا، ثم ينشئ قاعدة ويكتب رابطها في dexie-cloud.json
npx dexie-cloud whitelist https://اسم-نطاق-التطبيق   # أضف نطاق الاستضافة (ويُضاف localhost تلقائيًا)
cp .env.example .env             # ضع الرابط في VITE_DEXIE_CLOUD_URL=https://xxxx.dexie.cloud
npm run build                    # ابنِ وانشر dist/ كالمعتاد
```

ثم من **الإعدادات ← المزامنة بين الأجهزة** سجّل الدخول ببريدك (رمز تحقق لمرة واحدة، بلا كلمة مرور). عند أول تسجيل دخول تُرفع بياناتك المحلية الحالية إلى حسابك، وعلى الجهاز الآخر سجّل الدخول بالبريد نفسه.

ملاحظات:

- إذا تُرك `VITE_DEXIE_CLOUD_URL` فارغًا تُبنى نسخة محلية بالكامل بلا أي اتصال خارجي، وتختفي بطاقة المزامنة.
- المزامنة تعني أن نسخة من بياناتك تُحفظ لدى خدمة Dexie Cloud. راجع شروطها وخطتها المجانية قبل الاعتماد عليها لعمل تجاري.
- النسخة الاحتياطية JSON تبقى مفيدة كضمان إضافي مستقل عن أي خدمة.
- لا تضع الرابط في المستودع العام إن كنت تفضّل إبقاءه خاصًا؛ `.env` مُستثنى من git.

## النسخ الاحتياطي والاستعادة

- **تصدير:** الإعدادات ← «تصدير نسخة احتياطية (JSON)». يحتوي الملف على المشاريع والجلسات والإعدادات والمؤقت النشط إن وجد.
- **استيراد:** الإعدادات ← «استيراد نسخة احتياطية» ← اختر الملف. يتحقق التطبيق من صحته ويعرض ملخصًا وتحذيرات عن أي سجلات تالفة تم تجاوزها، ثم تختار:
  - **دمج:** إضافة السجلات وتحديث المتطابقة بالمعرّف مع الاحتفاظ ببياناتك الحالية.
  - **استبدال:** حذف كل ما لديك واستعادة النسخة كما هي (بعد تأكيد).
- **CSV:** من السجل أو التقارير أو الإعدادات، ملف متوافق مع Excel بالعربية.
- **الطباعة/PDF:** من صفحة التقارير زر الطباعة ← «حفظ كـ PDF».
- **حذف الكل:** الإعدادات ← منطقة الخطر، بتأكيد مزدوج.

**نصيحة:** على iPhone قد يحذف Safari بيانات المواقع غير المستخدمة لفترة طويلة. تثبيت التطبيق على الشاشة الرئيسية وتفعيل «التخزين الدائم» من الإعدادات يقللان هذا الاحتمال، لكن النسخة الاحتياطية هي الضمان الوحيد.

## الاختبارات

`npm test` يشغّل 36 اختبارًا تغطي:

- أمثلة التكلفة (30 د = 125، 1 س = 250، 1.5 س = 375، 2:15 = 562.50، 3:30 = 875، 8 س = 2000) ودقة الثانية.
- جلسة بها توقف مؤقت (لا يُحتسب)، وتوقفات متعددة، والإيقاف أثناء التوقف.
- استعادة مؤقت نشط بعد إغلاق قاعدة البيانات وإعادة فتحها.
- مؤقتات متزامنة على عدة مشاريع تُفوتر كل منها باستقلال، ومنع المؤقت الثاني عند تعطيل التزامن، وإنهاء الكل، وترحيل المؤقت القديم من المخطط 2 إلى 3.
- تعديل جلسة وإعادة حساب تكلفتها ووسمها «معدّلة يدويًا».
- تغيير السعر الافتراضي/سعر المشروع دون تغيير الجلسات القديمة، وإعادة الاحتساب عند الطلب.
- حفظ البيانات واستعادتها بعد إعادة الفتح.
- تصدير/استيراد النسخة الاحتياطية (دمج واستبدال)، رفض الملفات التالفة والغريبة، إصلاح السجلات المشوّهة، التعامل مع مؤقت غير مكتمل.
- إحصائيات التوزيع حسب اليوم ونوع المهمة.

إضافة إلى ذلك تم التحقق من الواجهة في Chromium بمقاس iPhone 13 و360px: اتجاه RTL، إنشاء مشروع، تشغيل/إيقاف/استئناف المؤقت، إعادة تحميل الصفحة مع استعادة الحالة والملاحظة، تنبيه الجلسة المفتوحة، منع المؤقت الثاني، جلسة يدوية 3:30 = 875 ر.س، رفض المدة السالبة، التقارير والتسعير، تصدير النسخة الاحتياطية، الوضع الداكن، تسجيل service worker، وعدم وجود تمرير أفقي.

## تغيير مخطط قاعدة البيانات مستقبلًا

في `src/db/db.ts` أضف إصدارًا جديدًا دون حذف القديم:

```ts
this.version(2).stores({ /* الفهارس الجديدة */ }).upgrade(async (tx) => { /* تحويل البيانات */ });
```

Dexie يطبّق الترحيلات تسلسليًا ويحافظ على البيانات الحالية. ارفع `SCHEMA_VERSION` ليُكتب في ملفات النسخ الاحتياطي.
